🟣 Спавнеров 2 тысячи Pro Incorporated™

Way Mod — это три уровня удобства. Сначала телепорт: блок перехода бросает игрока в любую точку любого измерения, а Shift+ПКМ возвращает назад. Потом спавн под контролем: спавнер выдаётся только оператором или в креативе — никаких вольных копий у выживших. А в v1.1.0 — фабрика: «Спавнер 2000 Pro» со прокачкой ядрами до спавна каждые полсекунды и добычей ×5, авто-воронка, собирающая предметы со всего чанка по фильтру, и воронка-передатчик, тянущая лут в сундук на другом конце склада.

/ 02 БЛОКИ И ПРЕДМЕТЫ

Блок перехода

waymod:way_block

ПКМ — телепорт к записанной цели в любом измерении. Shift+ПКМ — назад к точке отправления (даже после смерти).

Крафтовый спавнер

waymod:craftable_spawner

Моб задаётся командой /way spawner или яйцом спавна. Выдача — только оператору или в креативе, выживание без прав его не получает.

Спавнер 2000 Pro

waymod:spawner_2000_pro

Три строки мобов за раз, лимит живых 150, спавн раз в полсекунды после прокачки, режим «фарм»: авто-убийство с добычей ×5.

v1.1.0

Авто-воронка

waymod:auto_hopper

Собирает предметы со всего чанка по всей высоте — по фильтру или всё подряд — и складывает в соседний контейнер.

v1.1.0

Воронка-передатчик

waymod:hopper_transmitter

Shift+ПКМ + /way link — и передатчик тянет ресурсы из сундука в привязанный контейнер. Работает связкой с авто-воронками.

v1.1.0

/ 04 КОМАНДЫ
/way give <измерение> <x> <y> <z>блок перехода с записанной целью
/way set <измерение> <pos>задать цель блоку на позиции (поддерживает ~)
/way spawner <моб>крафтовый спавнер с мобом
/way spawnerpro <моб>Спавнер 2000 Pro сразу с мобом
/way link <pos>привязать передатчик к контейнеру после Shift+ПКМ

Измерения: overworld, nether, the_end (или полные id). give/set/link — оператор; спавнеры — оператор или креатив; выживание без прав не видит выдачи спавнеров.

Сборка из исходников

git clone https://github.com/Niokerter/waymod
cd waymod
gradlew.bat build

Нужна Java 21. Первая сборка скачает Minecraft (~1 ГБ), потом берётся из кеша.
